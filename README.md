# DATA DETECTIVE: THE IIITDM CAMPUS MYSTERY
> *“Every clue tells a story. Every pattern reveals the truth.”*

A browser-based educational Data Science detective game set across the campus of **IIITDM Kancheepuram (Indian Institute of Information Technology, Design and Manufacturing, Kancheepuram)**.

---

## 🏛️ Course Project Information
- **Course**: Data Science
- **Institute**: IIITDM Kancheepuram, Melakottaiyur, Chennai
- **Genre**: Detective mystery, campus exploration, interactive simulation, data forensics
- **Philosophy**: **NO DIRECT QUIZZES OR MCQs.** Players learn Data Science by actively using real statistical tools to investigate and resolve anomalies generated by the fictional **CampusSync** data management platform.

---

## 🎮 Playable Campus Layout (Strictly 4 Sites)

The game features an illustrated 2D tactical campus map inspired by the IIITDM Kancheepuram layout:

| # | Playable Location | Code | Missions Contained | Learning Concepts |
|---|---|---|---|---|
| **1** | **Academic Complex** | `AB-101` | **Mission 1: The Corrupted Records**<br>**Mission 2: The Hidden Pattern** | Data cleaning, missing values, outliers, Mean vs. Median, Correlation vs. Causation |
| **2** | **Arjuna Sports Complex** | `ASC-SPORTS` | **Mission 3: Predict the Champion** | Linear regression, residuals, Mean Absolute Error (MAE), prediction |
| **3** | **Parking Area** | `PKG-MAIN` | **Mission 4: The Parking Pattern** | Experimental vs. theoretical probability, Monte Carlo trials, random variation |
| **4** | **Administration Block** | `ADM-CENTRAL` | **Mission 5: The Final Verdict** | Logistic regression, decision trees, confusion matrix, precision/recall |

*Other visible campus features (Ashwatha & Ashoka Hostels, Jasmine Girls Hostel, Student Dining Hall, central quad lawns, athletics track, and Melakottaiyur Main Gate) form the atmospheric campus background.*

## 🚀 Quick Start Guide (VS Code)

### Prerequisites
- Node.js (v18+ recommended)
- VS Code

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open the local URL displayed in the terminal (typically `http://localhost:5173`) in any modern browser.

### 3. Run Automated Tests
```bash
npm run test
```

## 🛠️ Architecture & Tech Stack

- **Vite** — Fast, modern ES module bundler.
- **HTML5 & Modern CSS** — Dark navy/charcoal detective UI with responsive HUD layout.
- **Procedural Web Audio API** — High-fidelity synthetic detective audio effects (clicks, radar pings, evidence chimes) requiring zero external audio assets.
- **LocalStorage State Manager** — Automatic client-side persistence for detective rank, score, unlocked missions, and collected evidence.
- **Statistically Verified Math Utilities** — Mathematical functions for mean, median, mode, variance, standard deviation, Pearson correlation, least-squares regression, and confusion matrix.
- **Vitest** — Automated testing suite verifying state transitions and calculations.
